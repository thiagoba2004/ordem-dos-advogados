# EA-000008-000001 — Constituição pública documental de Ordem dos Advogados

**Projeto:** PRJ-000008 — Ordem dos Advogados  
**Autoridade:** REQ-000008-20261010-001, aprovação humana de 10/10/2026; Gerador EA-000002-000024  
**Rota do Gerador:** B — Projeto existente, código e baseline preservados  
**Escopo autorizado:** documentos de constituição em repositório GitHub público, sem contratação, deploy ou ativação de GitHub Pages  
**Nível de maturidade inicial:** GOVENANCE_BASELINE_ESTABLISHED; não havia estratégia local anterior.

## Objetivo e produto verificável

Fixar a missão aprovada — Pesquisa e sistematização sobre a Ordem dos Advogados do Brasil (OAB), incluindo sua organização institucional, normas, ética, prerrogativas profissionais e funcionamento de seus órgãos. — e disponibilizar estrutura pública inicial com README, documento de missão/escopo, política de pesquisa/publicação, AGENTS referencial, registros locais, plano, estado/roadmap e perfil de módulos mantido pelo Gerador.

A **conclusão desta EA** comprova constituição documental e leitura pública via GitHub, não validação jurídica substantiva dos temas, publicação de portal web, representação oficial ou serviços ao público.

## Fronteiras

- O Projeto é **independente e não oficial**, não representando organizações ou entidades que pesquisa. Não usar logotipos oficiais como identificação própria.
- Dados privados de pessoas, documentos processuais sigilosos, credenciais, extratos e informações S2+ não entram no Git público.
- Fontes normativas e decisões precisam de verificação primária, data e recorte antes de afirmação substantiva.
- GitHub público não demonstra GitHub Pages, e criar documentos não comprova pesquisa nem produto web.
- Operações de código multiarquivo deverão ser encaminhadas ao executor correspondente quando surgir necessidade aprovada.
- Nova pesquisa/subproduto deve recuperar a estratégia e os gates locais; esta EA não antecipa publicações nem cria orçamento.

## Primeiro ciclo substantivo posterior à constituição

Preparar, sob estratégia local e escopo definido, um **inventário mínimo de fontes oficiais e temas**, antes de produzir sínteses jurídicas. Isso requer pesquisa efetiva e verificação datada; não é declarado concluído nesta EA. Não reabrir a constituição apenas porque uma pesquisa futura está pendente.
