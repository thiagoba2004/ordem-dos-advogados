# SCIV — governanca-geral/mensagens

PRJ-000008 — pesquisa independente e não oficial.

Provisão técnica desativada: ON_DEMAND, enabled=false. Nenhuma leitura, mensagem ou movimentação automática. Somente S0 público e S1 revisado; proibidos S2+, segredos e dados privados.
